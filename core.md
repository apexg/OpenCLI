  ├────────────────────────────┼─────────────────────────────────────────┼─────────────────────┤

  ├────────────────────────────┼─────────────────────────────────────────┼─────────────────────┤

  ├────────────────────────────┼─────────────────────────────────────────┼─────────────────────┤

  └────────────────────────────┴─────────────────────────────────────────┴─────────────────────┘

  ---
  上下文是否清洁？

  是的，上下文非常清洁：

  1. browser state - 只包含可交互元素，过滤了不可见、广告、脚本元素
  2. browser network - 自动过滤静态资源(js/css/img)，只保留API请求
  3. browser find - 只返回匹配元素，不返回完整DOM
  4. Adapter输出 - 经过pipeline的map/limit/filter处理，返回精炼数据

  每个命令输出都是结构化JSON，Agent可以直接解析使用，无需额外处理。

  例如：
  - 搜索框定位：browser find --css "input[placeholder*='搜索']" → {matches_n: 1, entries: [{ref: 1}]} → Agent用 browser click 1 点击
  - 热门列表：opencli bilibili hot -f json → [{"rank":1,"title":"...","play":2255271}] → Agent直接读取数据
